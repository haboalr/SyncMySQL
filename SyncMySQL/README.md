Ab Version 1.3 kann das Identifikationsformat optional auf "Custom" gesetzt
werden. Dadurch sind beliebige Zeichenfolgen erlaubt und es wird keine
Formatprüfung mehr durchgeführt.

Ab Version 1.4 sind auch beliebige BKS-Werte möglich. Die Eingabefelder zur
Metererstellung prüfen keine feste Struktur mehr.
